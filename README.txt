ACCOUNTING SOFTWARE — REPLACEMENT STARTER

Replace the contents of the index.html file used by your GitHub Pages site with the supplied index.html. Commit the change, wait for GitHub Pages to redeploy, then refresh the site.

Working features: navigation, Year 12/Year 13 topic filters, sample MCQ/calculation/written questions with feedback and model answers, score tracking, virtual earnings, journal-entry practice, character selection, virtual room shop, progress saved in the browser.

Limitations: it is a learning simulator, not professional accounting software; virtual money is not real; the room is a simple 2D scene, not a full 3D Roblox-style game or driving simulator; the topic order is suggested and is not confirmed as Wyke's official scheme; browser reminders are not dependable while closed, so set a daily phone alarm.
